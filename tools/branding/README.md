# Tweebbo monogram

`tweebbo-mark.png` is an unchanged copy of `Tweebbo-designs/brandkit-v3/logos/monogram-native.png` (38 x 59 RGBA). The shared asset packer reduces it offline with a box filter: a 10 x 16 sprite for the 3DS header, or an 18px bounding box for Switch/Vita with `PACK_HD=1`. The 3DS adaptation comes from `../Tweebbo-3DS-smart-poc`, documented in the owner's `Tweebbo 3DS Smart+Classic.pdf`. Draw at 1:1 on whole pixels with no enclosing circle.
