# Tweebbo for Nintendo 3DS

Play in the same hotel as [tweebbo.lol](https://tweebbo.lol), with shared rooms, friends, furniture and pets. The room stays on the top screen while you chat and use the touch controls below.

**[Download for Nintendo 3DS](https://github.com/Tweebbo/tweebbo-3ds/releases/latest)** · [Release notes](docs/RELEASE.md)

![Building a room on Nintendo 3DS](docs/visual/build-mode.png)

## Install

You need a Nintendo 3DS or 2DS with custom firmware (Luma3DS).

- Install `tweebbo.cia` with FBI.
- Or copy `tweebbo.3dsx` to `sdmc:/3ds/tweebbo.3dsx` and launch it from the Homebrew Launcher.

<details>
<summary>Install with a QR code</summary>

Open FBI → Remote Install → Scan QR Code. This code always downloads the latest CIA.

![Latest CIA download QR code](docs/download-qr.png)

</details>

Tweebbo offers updates inside the game. You can also check from Help → Check for updates.

## In the hotel

- Create and furnish rooms, browse the catalogue and trade furniture.
- Chat, visit friends, change your look and adopt pets.
- Play Fast Food, Battle Ball, Snow Storm and board games. Casino games use credits.
- Use the same character on the web and consoles with your private character code. Offline practice with bots is also available.

## Controls

| Control | Action |
| --- | --- |
| Circle Pad | Walk |
| D-Pad | Walk or navigate lists |
| A | Talk, use nearby furniture or confirm |
| B | Sit / stand, close or cancel |
| X / Y | Wave / dance |
| L / R | Room overview; rotate furniture while building |
| SELECT | Switch windows |
| START | Quit |
| Touch screen | Open panels, type, scroll lists and select people or furniture on the minimap |

See the [player guide](docs/GUIDE.md) for building controls, saved progress and update details.
