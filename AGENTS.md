# Tweebbo 3DS: notes for contributors

Read `README.md` and `docs/ONLINE.md`. This is the Nintendo 3DS client of Tweebbo and it plays in the same world as tweebbo.lol; the reference behaviour is the web edition (client and server).

- The protocol must match the web edition's `server/src/proto.rs` (version 6, HELLO with platform byte `1`). If it changes there, update `source/proto.h`, `source/world.c` and `source/net.c`.
- Features must match the web; the 3DS only changes how they are used (buttons, Circle Pad, touch). When something is added on the web, add it here.
- `source/sim.c` mirrors the server room rules for offline mode. If rules change, update the tests in `tests/`.
- `source/gen/` is generated by `tools/pack.py`; never edit it by hand.
- Verify with `make -C tests`, `make -C tests online` (local server on 8092) and, for visual changes, `NET=host tools/emu/run.sh tools/emu/steps-online`.
- Never show or log tokens (`token-*.txt` on the SD card, the "Save / restore character" code).
- Everything in this repository (code, comments, documentation, interface and commit messages) is written in English.
