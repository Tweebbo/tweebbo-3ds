# Tweebbo for Nintendo 3DS 1.3.6

This update is optional. You do not need to install it immediately. Keep playing
on your current version and update whenever convenient.

- Adds support for smaller downloads in future updates, reusing unchanged installed
  game files. Versions through 1.3.5 first need this complete bridge update.
- Compares small and full download sizes and shows download/preparation progress.
- Offers an explicit full download when a small update cannot be used.
- Reduces repeated player and furniture lookups, including on original Nintendo 3DS.
- Keeps your character, settings and previous features.

Install with the in-game updater, or install the CIA with FBI / replace the 3DSX
in the Homebrew Launcher. Close and reopen Tweebbo after installation. Keep your
saved SD data. Reconstructing and installing updates still needs space for the
complete package on SD.

Host regression, real updater-worker tests and ARM builds pass. Physical-console
installation/performance acceptance remains pending; no hardware FPS or battery
improvement is claimed. Full changelog: https://tweebbo.lol/changelog
