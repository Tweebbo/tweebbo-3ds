# Tweebbo for Nintendo 3DS 1.3.3

Play in the same hotel as PC, mobile, Nintendo Switch and PlayStation Vita.

- Football: Game Balls, team goals and scoreboards from the Football catalogue. Walk into a ball to kick it, or step towards it to dribble. Goals update matching team scoreboards.
- Room owners can switch on dance floors and other walk-on furniture with lights from the furniture window or the nearby action prompt.
- Retains the playlist, readable notices and pet texture fixes from the previous updates.

Install `tweebbo.cia` with FBI, or copy `tweebbo.3dsx` to the Homebrew Launcher. Existing players can use the in-game updater.

Host regression checks pass. Physical-console performance and DSP audio remain unverified for this update.
